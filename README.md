# NBA Playoff Predictor Web App

## Overview

This project is a Flask web application that predicts NBA matchup win probabilities using 2024–2025 season performance data and head-to-head results.

Users select two NBA teams through a web interface, and the Python backend calculates probability-based predictions using season records and historical matchup performance.

## Features

- Interactive web interface
- Python Flask backend
- NBA team selection dropdowns
- Head-to-head analysis
- Season record comparison
- Probability-based predictions
- Excel data integration using Pandas

## Installation

### Requirements

- Python 3.14+
- pip

### Install Dependencies

```bash
py -3.14 -m pip install -r requirements.txt
```

### Run Application

```bash
py -3.14 app.py
```

Open:

```text
http://127.0.0.1:5000
```

in your browser.
